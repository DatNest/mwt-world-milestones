# Merged World Tracker — World Milestones Fork (экспериментальная версия)

Основа: присланные исходники MWT **2.13.0**. Исходный архив пользователя не изменён.

## Что добавлено

- **🌐 World Milestones: OFF/ON** во вкладке Story Planner → Settings, по умолчанию **OFF** и отдельно для каждого чата.
- Только сюжетные арки, начинающиеся с **S1E01**, **S1E02**, **S2E01**, **S3E01** и т. д., считаются мировыми вехами. Другие арки, включая отношения и личные цели NPC, автоматика не закрывает и не переключает.
- Каждые **5 ответов ИИ**, если включена новая функция и есть активная сезонная веха, запускается штатная проверка Story Planner **Check progress** через настроенный API. Только положительные предложения для мировых вех с проверенной дословной цитатой из RP применяются автоматически. Проверяются идентичность чата, ревизия арки и источник; изменения попадают в History.
- После подтверждённого разрешения текущей вехи следующий припаркованный эпизод становится Active и получает Pin + Focus, чтобы участвовать в режиме Focused only. **S1E10 → S2E01 → ... → S3E01** работает без правки кода, если соответствующие арки добавлены.
- Случаи отсутствующего предшествующего эпизода, дублирующихся кодов, незавершённой вехи или уже активного эпизода не вызывают перехода. Автоматика **не генерирует** арки, их нужно создать/импортировать заранее.

## Ограничения

- **Экспериментально.** Синтаксис изменённых JS-файлов и шесть независимых unit-тестов проверены, но полноценный тест в SillyTavern и полный набор Vitest не запускались: зависимости Vitest недоступны в данной среде.
- Проверка цитаты не гарантирует, что интерпретация ИИ семантически правильна: **ложные срабатывания возможны**. Для отката есть Story Planner → History → Revert.
- Прогресс подтверждается **по сообщениям RP**; записи только в World State или спрятанные внутренние планы NPC не всегда служат доступным доказательством для автоматического закрытия арки. Мир может развиваться за кадром, но факт завершения нужно явно зафиксировать в повествовании, чтобы автоматика его распознала.
- Не путать обычный **Auto** (перегенерация Story Planner) с **World Milestones** (проверка фактов и переход между сезонами). На первом тесте рекомендуется оставить обычный Auto **OFF**.
- Версия присланных исходников 2.13.0; у пользователя на экспортированном бэкапе была 2.11.2. Обновление может затронуть штатные миграции MWT. Сначала сделайте бэкап.
- Не гарантируется срабатывание строго через пять сообщений: если API недоступен или генерация уже идёт, проверка откладывается.

## Установка БЕЗ двух одновременно работающих копий

1. В MWT экспортируйте **свежий полный резервный бэкап** чата; сохраните вне папки расширения.
2. Полностью остановите SillyTavern.
3. Найдите **текущую папку Merged World Tracker**. Обычно это `SillyTavern/public/scripts/extensions/third-party/merged_world_tracker/` (см. исходный README), но у других установок путь может отличаться. Определяйте папку по `manifest.json` и названию MWT.
4. **Переместите** её копию в безопасную папку **вне каталогов расширений** — например, в `Documents/MWT_original_backup/`. Простое переименование внутри `third-party` может оставить её активной и вызвать два запуска.
5. Из этого ZIP возьмите папку `merged_world_tracker` и положите **на место исходной**. Должен остаться **ровно один** активный экземпляр MWT.
6. Запустите SillyTavern. Проверьте, что MWT открывается, а в Story Planner → Settings появилась кнопка `🌐 World Milestones: OFF`.
7. Проверьте, что в чате видны прежние World State / Chronicle / отношения. Включите `🌐 World Milestones: ON` **только после** проверки.
8. Убедитесь, что Story Planner использует действующий API Connection Profile; иначе автоматическая проверка фактов не заработает.

### Добавление сезонов 2 и 3

Создайте/импортируйте арки с точными префиксами заголовков:

- `S2E01 — Название первого эпизода` (Parked)
- `S2E02 — Название следующего эпизода` (Parked)
- `S3E01 — Название первого эпизода третьего сезона` (Parked)

При необходимости оставьте произвольный текст в `activateWhen`: новая автоматика ориентируется на **код эпизода и подтверждённый статус предыдущего**, не на свободную формулировку `activateWhen`.

**Не начинайте личные арки, не привязанные к эпизодам, с `S2E...`**, иначе они станут участниками сезонного перехода. Для них используйте обычные названия.

### Откат

1. В Story Planner нажмите `🌐 World Milestones: OFF`.
2. В MWT экспортируйте текущий бэкап, если после установки появились новые ценные события.
3. Остановите SillyTavern, удалите из каталога расширений **только папку форка**.
4. Верните сохранённую оригинальную папку на прежнее место и перезапустите ST.
5. Если нужно вернуть **данные**, восстановите сохранённый бэкап MWT через штатный Restore и внимательно проверьте Dry Run. Откат расширения и откат данных — разные операции.
